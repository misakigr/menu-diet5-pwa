# menu-diet5-pwa

Public GitHub Pages mirror of the Diet No. 5 menu PWA.

This repository is generated. The canonical source lives in the private
`menu_generator_dev` repository under `pwa/`; edit it there and republish with
`scripts/deploy_phase18_pages.sh`.

The published bundle is deliberately inert: it contains no backend address, no
access key and no data. The application stays unusable until a device is paired
through a one-time pairing link that the data owner generates themselves.
